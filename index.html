Test Planning & Tracking

Vehicle & Test Library

Vehicles and test sessions are tracked independently, so changes made to a vehicle after testing stay fully recorded, and you can always see the vehicle's exact state at test time.

More

Feature · 03

03

Automated Calculation

A full computation layer is modeled for every annex, so testers can focus on capturing data instead of rebuilding calculation logic for each configuration.

More

Feature · 04

04

Direct MDF/MF4 Capture

Upload MDF/MF4 files directly and let the tool compute blocking duration, stopping distance, and pressure response times automatically, instead of manually combing through hundreds of files by hand.

More

Feature · 05

05

Auto Save, History & Updates

The tool auto saves continuously, so data persistence is never in question, and a complete history of every test session is kept for testers to browse at any time. Tool updates never affect already persisted data.

More

Feature · 06

06

Organize & Upload

Connects directly to SharePoint and internal network servers, so measurement data can be organized by annex and uploaded in a single step. A built in upload manager runs in the background, letting testers keep working while the upload continues.

Architecture

Tauri Native Shell

React UI (Frontend)

View & Routing

React 19 & TypeScript 6.0 powered by Vite. Uses React Router (HashRouter) for native app navigation.

Vite Framer Motion

State & Validation

Domain-scoped Zustand stores for isolated screen logic. Forms powered by React Hook Form + Zod.

Zustand Zod

Styling & Charts

Tailwind CSS 4.3 for utility-first styling. uPlot for high-performance time-series signal rendering.

Rust Core (Backend)

Tauri IPC Bridge

Type-safe asynchronous message passing between React and Rust. Isolates the UI from OS-level operations.

invoke() events

Off-thread Binary Parsing

Parses high-frequency CANape .mdf / .mf4 vehicle data natively using mdf4-rs and vendored C++ mdflib.

mdf4-rs FFI

Network & Auth

Handles SharePoint uploads via reqwest. Secures OAuth refresh tokens using Windows Credential Manager.

Local Persistence

SQLite Databases

Two isolated, portable DBs (vehicles.db & sessions.db) accessed via tauri-plugin-sql to prevent lock contention.

Measurement Archives

Raw .mdf test instances organized into structured ZIP archives locally before upload.

Cloud Integrations

Microsoft Graph API

OAuth Authorization Code + PKCE flow to securely upload certification-ready reports to SharePoint.
