Brake certification that reads the regulation, not summaries of it.

A desktop tool for planning, measuring, and calculating ECE R13 Annex 13 / AIS 113 trailer brake performance — every formula cross-checked directly against the source regulation text, not transcribed from a spec sheet.

§01

What it does

From a vehicle library to a calculated verdict — one guided workflow, not a spreadsheet.

01

Vehicle library

Trucks and trailers — semi, drawbar, centre-axle, dolly — with full axle configuration, brake hardware, and a chronological edit history.

02

Guided test wizard

Select which regulation tests to run, configure the vehicle combination and ABS/EBS system, then map every sensor and modulator assignment.

03

Adhesion utilization engine

k-factor determination, zRAL derivation, and the high-μ / low-μ / split-μ verdicts — computed from the regulation's own formulas.

04

Session continuity

Every run autosaves and survives a crash or restart, and can be resumed, duplicated, or compared side-by-side against other sessions.
