R13 Copilot

Brake certification, read straight from the regulation.

A desktop tool for planning, measuring, and calculating ECE R13 Annex 13 / AIS 113 trailer brake performance — every formula cross-checked against the source regulation text, not summarized from a spec sheet.

What it does

One guided workflow, not a spreadsheet.

From a vehicle library to a calculated verdict, every step is built for the actual certification process.

Adhesion utilization engine

k-factor determination, zRAL derivation, and the high-μ / low-μ / split-μ verdicts — computed directly from the regulation's own Annex 13 formulas.

Vehicle library

Trucks and trailers — semi, drawbar, centre-axle, dolly — with full axle configuration and a chronological edit history.

Guided test wizard

Select which regulation tests to run, configure the vehicle combination, and map every sensor and modulator assignment.

Session continuity

Every run autosaves and survives a crash or restart, and can be resumed, duplicated, or compared side-by-side.

Measurement files

Attach real CANape .mdf/.mf4 files, organize them into a structured archive, and upload to SharePoint or a network share.

“Not a formula transcribed from a summary — the regulation text itself, cross-checked line by line.”
Built on

A native desktop shell, real persistence.

No cloud dependency for the core certification workflow.
